# style-scape
This project explores how different deep learning models classify natural vs. stylized scenes. It includes training scripts for AlexNet, BagNet, CLIP, DINOv2, SimCLR, and explainability tools Grad-CAM, LIME. 
To run scripts, open train_classifiers.ipynb on Google Colab, connect to this repository by running the first few cells, and run !python [file name].
